# Yallakora Match Scraper

A simple Python script that scrapes football match results for a chosen date and saves them to a CSV file.

**For learning purposes only.**

## Requirements

pip install requests beautifulsoup4 lxml

## How to use

1. Run scraper.py
2. Enter a date in MM/DD/YYYY format
3. Open the generated matches.csv file

## Output

The CSV contains: Team A, Score A, Score B, Team B, Time
